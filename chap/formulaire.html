Formulaire et constantes

Le peu qu’il faut savoir par cœur

Un formulaire long est un piège : on s’y perd, et on finit par appliquer une formule hors de ses hypothèses. Pour chaque chapitre, seulement les quelques relations à connaître sans hésiter ; tout le reste se retrouve à partir d’elles. Sous chaque liste, les méthodes qui servent le plus dans le chapitre.

Analyse dimensionnelle et ordres de grandeur

  • À savoir par cœur : \([v] = LT^{-1}\), \([a] = LT^{-2}\), \([F] = MLT^{-2}\), \([E] = ML^2T^{-2}\), \([P] = ML^2T^{-3}\). Les autres dimensions se retrouvent avec une loi simple (\(p = F/S\), \(P = UI\), \(U = RI\)…).
  • L’argument de exp, ln, sin est sans dimension ; l’analyse dimensionnelle donne une loi à une constante près.
  • Lois d’échelle : longueurs × λ, surfaces × λ², volumes et masses × λ³.
  • Incertitudes : absolues qui s’ajoutent (en quadrature) pour une somme, relatives pour un produit ; \(u(x^n)/x^n = n\,u(x)/x\).

Méthodes clés : Vérifier l’homogénéité, deviner une loi · Tester les cas limites · Estimer un ordre de grandeur · Raisonner en rapports · Évaluer et propager une incertitude.

Outils mathématiques

  • Dérivées : \((t^n)' = nt^{n-1}\), \((\mathrm e^{at})' = a\,\mathrm e^{at}\), \((\cos\omega t)' = -\omega\sin\omega t\), \((\sin\omega t)' = \omega\cos\omega t\), \((\ln t)' = 1/t\).
  • Pour \(x \ll 1\) : \((1+x)^n \approx 1 + nx\), \(\sin x \approx x\), \(\cos x \approx 1 - x^2/2\), \(\mathrm e^x \approx 1 + x\), \(\ln(1+x) \approx x\).
  • \(\int_a^b f = F(b) - F(a)\) avec \(F' = f\) ; éléments : tranche \(L\,\mathrm dz\), couronne \(2\pi r\,\mathrm dr\), pelure \(4\pi r^2\,\mathrm dr\) ; \(\langle\cos^2\rangle = \tfrac12\).
  • \(\tau\dot y + y = y_\infty\) : \(y = y_\infty + (y_0 - y_\infty)\,\mathrm e^{-t/\tau}\) ; 63 % à \(\tau\), 99 % à \(5\tau\).
  • \(\ddot y + \omega_0^2 y = 0\) : \(y = A\cos(\omega_0 t + \varphi)\), \(T_0 = 2\pi/\omega_0\), \(A = \sqrt{y_0^2 + (\dot y_0/\omega_0)^2}\).

Méthodes clés : Développer au premier ordre en un petit paramètre · Découper en éléments et intégrer · Écrire et reconnaître une équation différentielle · Chercher un extremum · Différentier le logarithme.

Mécanique du point

  • Uniformément accéléré : \(v = v_0 + at\), \(x = x_0 + v_0t + \tfrac12at^2\), \(v^2 - v_0^2 = 2a\,\Delta x\). Tir : portée \(\dfrac{v_0^2\sin2\alpha}{g}\), flèche \(\dfrac{v_0^2\sin^2\alpha}{2g}\).
  • Circulaire : \(v = R\omega\), accélération centripète \(v^2/R = \omega^2R\).
  • Newton : \(m\vec a = \sum\vec F\). Frottement solide : \(T \le \mu N\), égalité au glissement.
  • Énergie : \(\Delta E_c = \sum W\) ; \(E_p = mgz\), \(\tfrac12k(\ell - \ell_0)^2\). Puissance \(\vec F\cdot\vec v\).
  • Chocs : \(\sum m\vec v\) conservée ; énergie cinétique conservée seulement si le choc est élastique.

Méthodes clés : Bien choisir le système · Utiliser une loi de conservation · Écrire la condition d’existence.

Approche énergétique

  • \(\Delta E_c = \sum W\) ; \(W = \vec F\cdot\vec d\) ; \(P = \vec F\cdot\vec v\) ; avec frottement \(\Delta E_m = W_\text{nc}\).
  • \(F_x = -\dfrac{\mathrm dE_p}{\mathrm dx}\) ; équilibre : \(E_p\) extrémale ; stable si minimum.
  • Un paramètre : \(E = \tfrac12m_\text{eff}\dot q^2 + \tfrac12\kappa q^2\) donne \(\omega_0 = \sqrt{\kappa/m_\text{eff}}\).
  • Choc élastique sur cible immobile : \(V = \dfrac{2m}{m + M}v\) ; fraction d’énergie transmise \(\dfrac{4mM}{(m + M)^2}\).
  • Deux oscillateurs identiques couplés (CPGE) : découpler avec \(s = x_1 + x_2\) et \(d = x_1 - x_2\).

Méthodes clés : Utiliser une loi de conservation · Un seul paramètre : écrire l’énergie, puis la dériver · Chercher l’équilibre comme un minimum d’énergie.

Mécanique céleste

  • Gravitation : \(F = \dfrac{GMm}{r^2}\) ; pesanteur \(g = \dfrac{GM}{R^2}\) ; \(E_p = -\dfrac{GMm}{r}\).
  • Orbite circulaire : \(v = \sqrt{GM/r}\), \(T^2 = \dfrac{4\pi^2}{GM}r^3\) ; énergie \(E = -\dfrac{GMm}{2a}\).
  • Kepler : \(T^2/a^3\) identique autour d’un même astre. Loi des aires : \(r_pv_p = r_av_a\).
  • Vitesse de libération : \(\sqrt{2GM/R}\) (Terre : 11,2 km/s) ; orbite basse : 7,9 km/s, 84 min ; géostationnaire : \(r = 42\,200\) km.

Méthodes clés : Raisonner en rapports · Utiliser une loi de conservation.

Oscillateurs

  • \(\ddot x + \omega_0^2x = 0\) : \(x = A\cos(\omega_0t + \varphi)\), \(T = 2\pi/\omega_0\). Ressort : \(\omega_0 = \sqrt{k/m}\) ; pendule : \(\sqrt{g/\ell}\) ; LC : \(1/\sqrt{LC}\).
  • Énergie : \(\tfrac12m\dot x^2 + \tfrac12kx^2 = \tfrac12kA^2\) ; \(v_\text{max} = A\omega_0\).
  • Ressorts en série : \(1/k = 1/k_1 + 1/k_2\) ; en parallèle : \(k = k_1 + k_2\).
  • Petites oscillations : \(\omega_0^2 = \dfrac1m\dfrac{\mathrm d^2E_p}{\mathrm dx^2}\) à l’équilibre.
  • Amorti (CPGE) : \(\ddot x + \dfrac{\omega_0}{Q}\dot x + \omega_0^2x = 0\) ; amplitude \(\propto \mathrm e^{-\omega_0t/2Q}\) ; largeur de résonance \(\omega_0/Q\).

Méthodes clés : Linéariser autour d’un équilibre · Un seul paramètre : écrire l’énergie, puis la dériver.

Référentiels non galiléens

  • Translation : \(\vec v = \vec v\,' + \vec v_{O'}\), \(\vec a = \vec a\,' + \vec a_{O'}\) ; force d’inertie \(-m\vec a_{O'}\), pesanteur effective \(\vec g - \vec a_{O'}\).
  • Rotation uniforme : centrifuge \(m\omega^2\,\overrightarrow{HM}\) (\(E_p = -\tfrac12m\omega^2r^2\)) ; Coriolis \(-2m\,\vec\omega\wedge\vec v\,'\).
  • Terre : \(\Omega = 7{,}3\times10^{-5}\ \text{rad·s}^{-1}\) ; \(\Omega^2R_T = 0{,}034\ \text{m·s}^{-2}\).

Méthodes clés : Changer de référentiel · Remplacer g par une pesanteur effective · Chercher l’équilibre comme un minimum d’énergie.

Mécanique du solide

  • \(M\vec a_G = \sum\vec F_\text{ext}\) ; \(\vec v_P = \vec v_G + \vec\omega\wedge\overrightarrow{GP}\).
  • Moments d’inertie : anneau \(MR^2\), disque \(\tfrac12MR^2\), boule \(\tfrac25MR^2\), tige (milieu) \(\tfrac1{12}ML^2\) ; axes parallèles \(J_\Delta = J_G + Md^2\).
  • Axe fixe : \(J\ddot\theta = \sum\mathcal M\), \(E_c = \tfrac12J\omega^2\) ; pendule pesant \(T = 2\pi\sqrt{J/mgd}\).
  • Roulement sans glissement : \(v_G = R\omega\) ; \(E_c = \tfrac12Mv_G^2 + \tfrac12J_G\omega^2\).

Méthodes clés : Séparer le mouvement du centre de masse et la rotation autour de lui · Écrire le roulement sans glissement · Choisir le point où calculer les moments · Un seul paramètre : écrire l’énergie, puis la dériver.

Statique des fluides

  • \(F = PS\) ; 1 bar = \(10^5\) Pa ≈ 1 atm = 760 mmHg.
  • \(\dfrac{\mathrm dP}{\mathrm dz} = -\rho g\) (\(z\) vers le haut), d’où \(P = P_0 + \rho g h\) dans un liquide : 1 bar tous les 10 m d’eau.
  • Poussée d’Archimède : \(\vec\Pi = -\rho_\text{fluide}V_\text{immergé}\,\vec g\), appliquée au centre de poussée.
  • Gaz parfait : \(PV = nRT\), donc \(\rho = \dfrac{PM}{RT}\).

Méthodes clés : Suivre la pression le long d’un chemin · Remplacer un objet par le fluide qu’il déplace · Écrire l’équilibre : forces et moments.

Dynamique des fluides

  • Débit \(Q = Sv\) ; conservation \(S_1v_1 = S_2v_2\).
  • Bernoulli : \(P + \tfrac12\rho v^2 + \rho gz = \text{cste}\) sur une ligne de courant (fluide parfait, incompressible, stationnaire).
  • Nombre de Reynolds \(Re = \rho vL/\eta\) ; traînée de Stokes \(6\pi\eta Rv\) à petit \(Re\), quadratique \(\tfrac12 C_x\rho Sv^2\) à grand \(Re\).

Méthodes clés : Appliquer Bernoulli entre deux points bien choisis · Faire un bilan sur un volume de contrôle · Former les nombres sans dimension.

Tension superficielle

  • \(E = \gamma S\) ; force \(\gamma\ell\) le long d’un bord (\(2\gamma\ell\) pour un film à deux faces) ; eau : \(\gamma = 72\) mN·m⁻¹.
  • Laplace : \(\Delta P = 2\gamma/R\) (goutte), \(4\gamma/R\) (bulle de savon) ; Young : \(\gamma\cos\theta = \gamma_{SG} - \gamma_{SL}\).
  • Jurin : \(h = \dfrac{2\gamma\cos\theta}{\rho g r}\) ; longueur capillaire \(\ell_c = \sqrt{\gamma/\rho g}\) (2,7 mm pour l’eau).

Méthodes clés : Isoler une partie et écrire son équilibre · Chercher l’équilibre comme un minimum d’énergie · Former les nombres sans dimension.

Optique géométrique

  • \(n = c/v\) ; \(n_1\sin i_1 = n_2\sin i_2\) (réflexion totale si \(\sin i_1 > n_2/n_1\)) ; \(\dfrac{1}{\overline{OA'}} - \dfrac{1}{\overline{OA}} = \dfrac{1}{f'}\), \(\gamma = \overline{OA'}/\overline{OA}\).
  • Loupe \(G = d_m/f'\) (\(d_m = 25\) cm) ; lunette afocale \(G = f'_1/f'_2\) ; vergence \(V = 1/f'\) en dioptries.

Méthodes clés : Tracer les rayons particuliers · Enchaîner les images avec la relation de conjugaison · Suivre un rayon par une chasse aux angles.

Ondes et optique ondulatoire

  • \(\lambda = vT = v/f\) ; phase \(\omega t - kx\) avec \(k = 2\pi/\lambda\) ; déphasage \(2\pi d/\lambda\) ; intensité \(\propto\) amplitude².
  • Niveau sonore \(L = 10\log(I/I_0)\), \(I_0 = 10^{-12}\ \text{W·m}^{-2}\).
  • Doppler : \(f' = f\,\dfrac{v \pm v_o}{v \mp v_s}\) (haut : rapprochement) ; \(\Delta f/f \approx v_\text{rel}/v\).
  • Interférences : constructives si \(\delta = p\lambda\), destructives si \((p + \tfrac12)\lambda\) ; Young \(i = \lambda D/a\).
  • Corde ou tuyau ouvert : \(f_n = n\,v/2L\) ; battements \(f_b = |f_1 - f_2|\).
  • Diffraction : \(\theta \approx \lambda/a\) ; réseau \(a\sin\theta = p\lambda\).

Méthodes clés : Raisonner en différence de marche · Additionner des amplitudes complexes (vecteurs de Fresnel) · Imposer les conditions aux limites : modes propres · Traiter un effet Doppler.

Champ électrique

  • Coulomb : \(F = \dfrac{|q_1q_2|}{4\pi\varepsilon_0r^2}\) ; charge ponctuelle : \(E = \dfrac{q}{4\pi\varepsilon_0r^2}\), \(V = \dfrac{q}{4\pi\varepsilon_0r}\).
  • \(\vec F = q\vec E\) ; \(E_x = -\dfrac{\mathrm dV}{\mathrm dx}\) ; \(E_p = qV\) ; champ uniforme entre deux plaques : \(E = U/d\).
  • Condensateur : \(Q = CU\), plan \(C = \varepsilon_0S/d\), énergie \(\tfrac12CU^2 = Q^2/2C\).

Méthodes clés : Exploiter les symétries · Passer par le potentiel plutôt que par le champ · Se demander ce qui est constant : la charge ou la tension.

Champ magnétique et bobine

  • Force magnétique : \(\vec F = q\,\vec v\wedge\vec B\), perpendiculaire à la vitesse (ne travaille pas).
  • Bobine idéale (convention récepteur) : \(u = L\,\dfrac{\mathrm di}{\mathrm dt}\) ; énergie \(\tfrac12Li^2\) ; le courant est continu.
  • Circuit RL : \(\tau = L/R\), \(i(t) = \dfrac ER\left(1 - \mathrm e^{-t/\tau}\right)\) ; en régime continu la bobine idéale est un fil.

Méthodes clés : Tester les cas limites (instant initial, régime permanent) · Écrire et reconnaître une équation différentielle.

Particules chargées

  • Lorentz : \(\vec F = q(\vec E + \vec v\wedge\vec B)\) ; seul \(\vec E\) travaille : \(\tfrac12mv^2 = |q|U\).
  • Cyclotron : \(R = \dfrac{mv_\perp}{|q|B}\), \(\omega_c = \dfrac{|q|B}{m}\) ; pas de l’hélice \(v_\parallel T\).
  • Champs croisés : vitesse non déviée, et vitesse de dérive, \(v = E/B\).

Méthodes clés : Relier la vitesse à la tension accélératrice · Reconnaître le mouvement cyclotron · Champs croisés : chercher la vitesse de dérive · Écrire la condition d’existence : le seuil est le cas d’égalité.

Circuits électriques

  • Nœuds : \(\sum i = 0\) ; mailles : \(\sum u = 0\) ; Ohm : \(u = Ri\) ; \(R = \rho\ell/S\) ; \(I = neSv\).
  • Série : \(R = R_1 + R_2\) ; parallèle : \(1/R = 1/R_1 + 1/R_2\) ; condensateurs : règle inverse. Diviseur : \(U_2 = E\,\dfrac{R_2}{R_1 + R_2}\).
  • Puissance : \(P = UI = RI^2 = U^2/R\).
  • Premier ordre : \(x(t) = x_\infty + (x_0 - x_\infty)\mathrm e^{-t/\tau}\), \(\tau = RC\) ou \(L/R\) ; \(u_C\) et \(i_L\) continus, sauf cas limites (fil idéal aux bornes d’un condensateur chargé, condensateurs reliés directement : conservation de la charge).
  • Conservation de la charge d’un îlot (armatures reliées entre elles, sans générateur) : \(\sum q = \text{cste}\), toujours. Deux condensateurs reliés en parallèle : \(U = \dfrac{C_1U_1 \pm C_2U_2}{C_1 + C_2}\) (signe − si l’un est retourné) ; l’énergie n’est pas conservée.
  • CPGE : impédances \(R\), \(jL\omega\), \(1/jC\omega\) ; RLC série : \(\omega_0 = 1/\sqrt{LC}\), \(Q = \dfrac1R\sqrt{L/C}\).

Méthodes clés : Tester les cas limites · Écrire la conservation de la charge d’un îlot · Exploiter les symétries.

Thermodynamique et rayonnement

  • Gaz parfait : \(PV = nRT\) (\(T\) en K) ; \(P = \rho RT/M\) ; énergie cinétique moyenne \(\tfrac32k_BT\).
  • Premier principe : \(\Delta U = W + Q\) ; \(\Delta U = mc\,\Delta T\) ; changement d’état \(Q = mL\).
  • Adiabatique réversible (CPGE) : \(PV^\gamma\), \(TV^{\gamma-1}\), \(T^\gamma P^{1-\gamma}\) constants.
  • Moteur : \(\eta \le 1 - T_f/T_c\).
  • Transferts : conduction \(\dfrac{\lambda S}{e}\Delta T\) ; Newton \(hS\,\Delta T\) ; Stefan \(\sigma ST^4\) ; Wien \(\lambda_\text{max}T = 2{,}9\times10^{-3}\) m·K.

Méthodes clés : Utiliser une loi de conservation · Raisonner en rapports · Faire un bilan sur un volume de contrôle.

Relativité restreinte

  • \(\gamma = \dfrac{1}{\sqrt{1 - v^2/c^2}}\) ; durée propre la plus courte : \(\Delta t = \gamma\Delta t_0\) ; longueur propre la plus grande : \(L = L_0/\gamma\).
  • \(\vec p = \gamma m\vec v\), \(E = \gamma mc^2\), \(E_c = (\gamma - 1)mc^2\), \(E^2 = p^2c^2 + m^2c^4\) ; photon \(E = pc = h\nu\).
  • Énergie libérée par une réaction : \(|\Delta m|\,c^2\) ; 1 u = 931,5 MeV/\(c^2\) ; \(m_ec^2 = 0{,}511\) MeV.
  • Doppler (éloignement) : \(f = f_0\sqrt{\dfrac{1-\beta}{1+\beta}}\), \(\Delta\lambda/\lambda \approx \beta\).
  • CPGE : \(x' = \gamma(x - vt)\), \(t' = \gamma(t - vx/c^2)\) ; \(u' = \dfrac{u - v}{1 - uv/c^2}\) ; invariant \(E^2 - p^2c^2\).

Méthodes clés : Identifier la durée propre et la longueur propre · Utiliser un invariant relativiste · Faire un bilan masse-énergie.

Physique nucléaire

  • \({}^A_Z\mathrm X\) : \(A = Z + N\) ; conservation de \(A\) et de \(Z\).
  • \(E_\ell = \Delta m\,c^2\), \(\Delta m = Zm_p + Nm_n - m_\text{noyau}\) ; \(Q = (m_\text{avant} - m_\text{après})c^2\).
  • \(N(t) = N_0\,\mathrm e^{-\lambda t}\), \(t_{1/2} = \ln 2/\lambda\), activité \(A = \lambda N\) (Bq).

Méthodes clés : Faire un bilan masse-énergie · Raisonner en demi-vies · Passer d’une masse à un nombre d’entités.

Physique quantique

  • Photon : \(E = h\nu = hc/\lambda\), \(p = h/\lambda\) ; \(hc = 1\,240\) eV·nm.
  • Effet photoélectrique : \(E_{c,\max} = h\nu - W = eU_0\).
  • Transition : \(h\nu = |E_n - E_p|\) ; hydrogène \(E_n = -13{,}6\ \text{eV}/n^2\).
  • De Broglie : \(\lambda = h/p\) ; Heisenberg : \(\Delta x\,\Delta p \ge \hbar/2\).

Méthodes clés : Compter les quanta · Calculer dans des unités adaptées · Estimer une énergie par le confinement.
